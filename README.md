# NexusBoard

NexusBoard is a learning-oriented production-like backend project built with TypeScript, Node.js and NestJS.

The project evolves step by step from a simple NestJS application into a distributed microservice system.

## Goals

- Improve TypeScript knowledge.
- Learn NestJS deeply.
- Practice software architecture and domain modelling.
- Learn microservice communication and distributed systems.
- Build production-like infrastructure gradually.
